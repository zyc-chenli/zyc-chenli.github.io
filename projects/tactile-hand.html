From tactile input to hand gestures

Connect pressure sensing, learned recognition and robot action in a single ROS 2 pipeline.

View source on GitHub ↗Watch demo ↓

My contributions

  • Sensor integration. Built ROS 2 acquisition and visualisation nodes for a 5 × 5 pressure array, turning serial sensor readings into pressure images.
  • Recognition. Implemented a PyTorch CNN pipeline to recognise digit patterns from accumulated tactile input.
  • Physical interaction. Connected recognized digits to preset Linker Hand poses through ROS 2 gesture-control nodes and the vendor SDK.

Hardware demonstration

Touch → recognize → move

  1. AcquireA 25-channel pressure array captures tactile input.
  2. RecognizeThe classifier maps accumulated pressure images to a digit.
  3. ActuateA controller sends the corresponding preset hand pose.

The released gesture mapping covers digits 1–9. The video demonstrates the end-to-end behaviour; it is not an accuracy or latency benchmark.

Setup & reproduction notes ↗

Code & platform

The public repository includes the ROS 2 nodes, CNN training script and a small digit-image dataset. A trained checkpoint is not bundled; hardware and calibration are required to reproduce the physical demo.

The dexterous-hand platform and device driver are provided by LinkerBot’s ROS 2 SDK. My work focuses on the tactile acquisition, recognition and application-control pipeline.
