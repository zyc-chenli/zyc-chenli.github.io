Tactile Perception and Control for Dexterous Hands and Humanoid Locomotion

Developed tactile-to-gesture interaction for a dexterous hand and explored reinforcement learning for humanoid walking during a summer research placement.

Hand demonstration ↓Humanoid simulation ↓Hand source code ↗

Tactile interaction contributions

  • Pressure acquisition. Implemented a ROS 2 interface for a 5 × 5 pressure array, publishing sensor data and visualising tactile input as pressure images.
  • Digit recognition. Collected local pressure patterns and built a PyTorch digit-recognition pipeline to translate tactile input into gesture commands.
  • Joint-level actuation. Mapped recognised digits to Linker Hand L10 joint commands, connecting acquisition, inference and physical hand poses.

Touch → recognise → move

  1. AcquireA 25-channel pressure array captures tactile input.
  2. RecogniseA neural classifier identifies the digit pattern.
  3. ActuateThe controller sends the corresponding preset hand pose.

The released gesture map covers digits 1–9. The video demonstrates the interaction pipeline; it does not establish an accuracy or latency benchmark.

Humanoid locomotion simulation

Trained Unitree G1 locomotion policies in Isaac Lab as part of the same research placement.

  • Contact-aware observations. Added foot-contact observations to expose support and ground-contact information to the policy.
  • Reward refinement. Refined reward terms to support stable walking and more precise motion execution in simulation.

Public code and platform

The public hand repository contains the ROS 2 acquisition and control nodes, a PyTorch CNN training implementation and a small pressure-image dataset. A trained checkpoint is not bundled; hardware calibration is needed to reproduce the physical demonstration.

The device platform and driver are provided by LinkerBot’s ROS 2 SDK. The hand repository covers tactile recognition and hand control; the G1 work is presented here as a separate simulation component.
